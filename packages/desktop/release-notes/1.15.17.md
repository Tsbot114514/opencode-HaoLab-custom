# HaoLab OpenCode 1.15.17

## 新增

- 新增实验页面，可在独立沙箱中运行 Agent 对话、Stroop、简单反应时和 2-back 工作记忆实验。
- 新增页面切换菜单，可在正式页面、管理页面和实验页面之间切换。
- 新增模型请求重试上限配置 `retry.maxAttempts`，默认最多重试 5 次，可设置为 0 关闭重试。
- Markdown 文件新增 Word 式审阅模式，支持新增和删除修订、文本批注、下一处修订和下一处批注，并将审阅内容自动保存到原文件。

## 改进

- 修复旧会话在消息 ID 非单调时发送消息无响应的问题，改为按消息创建时间识别最新回合。
- 修复 Desktop 在消息 ID 回绕后将新消息显示在会话顶部，以及切换回历史会话时渲染异常、直到发送新消息才恢复的问题；历史加载、预取、实时更新和撤销重做均改为按消息创建时间排序。
- 修复会话压缩尾部预算失效的问题：默认保留最近 20 个回合的对话文本和最新回合的完整调用现场；超过预算时先将最新回合降级为文本，再从最早回合开始裁剪；旧压缩检查点升级后仍按纯文本尾部读取，避免历史工具输出重新进入上下文。
- 会话总结新增近期工具调用信息，保留关键参数、执行结果或错误以及对后续工作的影响，减少重复读取文件或执行命令。
- 修正 OpenAI OAuth 模式下 GPT-5.6 使用公共 API 上下文限额的问题，按 ChatGPT Codex 后端的 500K 总窗口和 372K 输入预算提前压缩。
- 升级 OpenAI AI SDK，并为 GPT-5.6 Sol、Terra 和 Luna 改用 `prompt_cache_options` 的 30 分钟隐式缓存配置，避免旧 `prompt_cache_retention` 参数导致请求失败。
- 重试状态显示当前次数和总次数，例如 `2/5`，并在等待期间保持可见。
- 改进实验页面的 Agent 隔离，实验内容无法直接访问凭据或调用本地工具。
- 修复 Agent 回复中列表内 LaTeX 块公式导致后续正文、标题和表格渲染错位的问题，兼容公式中的未转义百分号，并改进流式块公式显示。
- 修复 Markdown 自动保存后编辑器刷新和光标跳转的问题，保存期间保持连续输入和选区位置稳定。
- 改进 Markdown 批注交互：批注卡片与被批注文本水平对齐，框选文本后可直接添加批注，选中删除修订时可撤销删除，打开批注框后自动聚焦输入。
- Markdown 文件会按页签保存阅读位置，关闭或切换后重新打开时恢复到上次浏览位置；修复正文加载前的空容器将已保存位置覆盖为顶部的问题。
- 修复 Markdown 自动保存已成功但文件监听器仍误报外部修改的问题；冲突时新增“保存我的版本”，并修复粗体文本中的修订在重新加载后可能丢失字符、粗体标签后紧接中文时无法渲染的问题。
- 修复 Windows 文件监听事件使用 `/D:/...` 路径时，Agent 对已打开 Markdown 文件的修改偶尔无法同步到编辑器的问题。
- Markdown 审阅器支持按文档目录加载本地插图，图片文件被替换后自动刷新，并按页面宽度自适应显示；可点击图片添加、编辑和删除图片级批注。
- 修改数据存储路径并完成迁移后会自动重启 HaoLab OpenCode，避免应用继续使用旧目录产生数据不一致。
