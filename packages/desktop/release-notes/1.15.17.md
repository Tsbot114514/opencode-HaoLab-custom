# HaoLab OpenCode 1.15.17

## 新增

- 新增实验页面，可在独立沙箱中运行 Agent 对话、Stroop、简单反应时和 2-back 工作记忆实验。
- 新增页面切换菜单，可在正式页面、管理页面和实验页面之间切换。
- 新增模型请求重试上限配置 `retry.maxAttempts`，默认最多重试 5 次，可设置为 0 关闭重试。

## 改进

- 会话压缩默认最多保留最近 20 个文本回合，并将近期轮次一并纳入总结，改善压缩后继续任务时的上下文衔接。
- 会话总结新增近期工具调用信息，保留关键参数、执行结果或错误以及对后续工作的影响，减少重复读取文件或执行命令。
- 修正 OpenAI OAuth 模式下 GPT-5.6 使用公共 API 上下文限额的问题，按 ChatGPT Codex 后端的实际窗口提前压缩。
- 重试状态显示当前次数和总次数，例如 `2/5`，并在等待期间保持可见。
- 改进实验页面的 Agent 隔离，实验内容无法直接访问凭据或调用本地工具。
- 修复 Agent 回复中列表内 LaTeX 块公式导致后续正文、标题和表格渲染错位的问题，兼容公式中的未转义百分号，并改进流式块公式显示。

## 测试

- 增加实验流程、会话压缩、重试限制和配置校验的自动化测试。
