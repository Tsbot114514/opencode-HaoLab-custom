# HaoLab OpenCode 1.15.20

## 修复

- 默认单次模型请求的整体时长上限改为 20 分钟；响应头等待与 SSE 流停顿分别保留独立的 5 分钟保护，可通过 `timeout`、`headerTimeout`、`chunkTimeout` 配置覆盖或关闭。
- 修复空内容和开始事件重置重试预算的问题；仅收到非空思考、正文、工具参数或完整工具调用后重置连续失败计数，避免无实质进展的无限重试。
- 修复大型工作区备份时，一次展开大量消息或工具记录导致“Maximum call stack size exceeded”的问题，改为在一致性数据库事务中逐条读取并暂存记录。
- 修复会话记录总量超过 64 MiB 时无法导出、预览或生成覆盖前恢复包的问题。迁移包改为 SQLite v3 格式：清单保存项目身份和校验信息，会话记录放在 `sessions.sqlite` 中，不再整体写入 JSON 清单。
- 导出、预览、确认载入及覆盖前恢复包使用 SQLite 记录进行校验和载入，避免将完整消息历史同时载入内存。
- 修复 Windows 下来源会话路径大小写不一致时，已包含的附件路径未正确重绑到本机的问题。

## 保留与校验

- 继续备份项目工作文件、会话数据库记录、对应的 `sessions/<sessionID>/` 文件夹及会话差异记录；不删减对话、不截断工具输出。原有依赖和缓存排除规则仍适用。
- 清单保存数据库字节数、SHA-256、表结构及每张表的记录数和校验和；载入前检查 ZIP CRC、SQLite 结构、重复键及关联归属，拒绝损坏或超限记录。
- 保留时间对比、明确覆盖确认、内容变化检测、覆盖前恢复包、普通失败回滚及客户端会话缓存刷新。

## 使用说明

- 仅支持 SQLite v3 迁移包，不读取旧格式迁移包。请在源设备使用支持 v3 的版本重新导出，并在目标设备使用支持该格式的版本载入。
- 单个数据库字段上限 128 MiB、单条记录上限 256 MiB，超过时明确报错而不是截断。迁移包解压后总量上限为 10 GiB，ZIP 条目上限 100,000。
- 导出需要记录暂存空间，预览和载入需要解压校验及临时索引空间，覆盖还会保留恢复包。请在相关磁盘预留足够可用空间，并停止目标工作区的 agent、文件编辑和数据库写入。
- v3 可在 Windows、macOS 和 Linux 设备之间迁移；不包含 Git 历史、依赖缓存、撤销快照、目录外附件和外部数据库。迁移包与恢复包未加密，请妥善保管。

## 远程连接与通知

- Desktop 管理页可开启私有 Tailscale 远程连接，向已配对的设备发布当前侧栏目录清单；B 端按连接读取项目，并缓存已查看的会话与消息。
- 修复远程终端鉴权、关闭连接时撤销既有连接、跨设备项目列表加载以及管理页定时轮询造成的反复重建。
- Bark 通知区分本轮完成、运行出错、中断、等待回答及请求权限，附会话标题与短标识。推送请求可在管理页按服务器配置 curl GET/POST 模板，支持 `{{token}}`、`{{title}}`、`{{body}}` 和查询参数；旧纯 URL 保持原 POST JSON 行为。
- 管理页可一键保存 Bark GET 模板；粘贴官方 `/title/body` GET 示例时，服务器自动转换为动态通知标题与正文，不再把 `body` 当作固定文字推送。
- 修复恢复数据库后的缓存游标失效与本机跨数据库展示缓存混用；Windows 上的 Bark key 和包含 token 的请求模板限制为当前用户访问。
- 此版本包含会话侧栏索引迁移。A、B 两端需手动安装同版本本地替换包；安装前备份数据目录并停止活动会话。
