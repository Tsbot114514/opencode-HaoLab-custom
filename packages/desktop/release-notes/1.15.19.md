# HaoLab OpenCode 1.15.19

## 新增

- 管理页面新增“项目迁移包”：将项目文件、会话历史及会话本地材料导出为 ZIP，保存到指定位置，可通过云同步文件夹、共享磁盘或手动传输在设备间交换项目存档。
- 加载迁移包时按稳定项目标识匹配本地项目；默认直接增量合并，不要求预览令牌，只导入缺失或更新时间更新的完整会话，并保留本地独有及更新内容。
- 项目文件按路径和修改时间合并；缺失或更新的文件会导入，本地独有或更新的文件会保留。会话文件夹和 diff 仅跟随实际导入的会话复制。
- 完整校验、安全备份和破坏性完整替换改为显式选项，不再阻塞默认增量载入；普通执行失败仍回滚本次文件和数据库改动。
- sidecar 提供项目导出、快速预览和增量载入 API，并在 `/doc`、会话元数据和 SDK 中补充 agent 使用说明。

## 改进

- 修复模型流在思考过程中断线后，重连成功仍继续累计旧重试次数的问题；收到恢复后的首个有效流事件时会重置连续重试次数，并将会话状态从“重试中”恢复为“处理中”。
- 项目迁移包升级为版本 3，使用范围受限的 SQLite 数据库存储会话记录并进行流式校验和恢复，避免大型会话表转换为 JSON 或整体载入内存。
- 支持在 Windows、macOS 和 Linux 之间迁移项目，源设备路径会按其平台规则校验，再映射到目标设备目录。
- 载入完成后通知已连接客户端刷新目标项目及子目录的会话列表、消息、差异和待办缓存，防止继续显示覆盖前的记录或被旧请求结果覆盖。
- 快速预览仅读取 manifest、ZIP 中央目录和本地会话摘要，不再对整个迁移包、本地项目文件和全部会话记录重复执行全量哈希。
- 导入时重建本机项目关联和会话元数据，并重新绑定项目、会话目录内附件的结构化路径，保留历史对话原文。
- 增加迁移包路径、大小、重复条目和关联记录校验；检测活动目标会话，并将导入的项目配置、会话工具及自定义组装脚本隔离到 `backup-disabled` 目录，供用户检查后启用。
- Git 状态扫描会跳过超过补丁预算的未追踪大文件，避免二进制文件或迁移包占用过多内存；Codex 模型筛选兼容整数形式的新主版本标识。

## 使用说明

- 当前支持相同操作系统、兼容数据库结构的设备间迁移，项目和应用数据目录可以不同；本功能不直接连接云服务商，不自动上传或持续同步。
- 不打包 Git 历史、依赖和缓存目录、历史撤销快照、项目及会话目录之外的附件或外部数据库。增量合并保留本地根目录 `.git` 和本地独有内容。
- 迁移包和恢复包未加密，可能包含 `.env`、源码和对话中的敏感信息，请妥善保管。打包前应停止其他 agent、文件编辑和数据库写入。
- 如遇进程或系统中断，恢复日志会阻止继续载入，需要按日志人工恢复；不要直接删除恢复锁文件。暂不提供自动断电恢复。
