# HaoLab OpenCode 1.15.18

## 改进

- 适配 OpenAI GPT-6 Astra，在 ChatGPT Pro/Plus OAuth 模式下不再因整数主版本模型 ID 被过滤，并支持 `gpt-6-astra`、Fast 和 Pro 模式出现在模型列表中。

## 修复

- 修复模型请求重连后，已恢复思考或正文输出却仍累计重试次数的问题。收到非空思考、正文、工具参数或完整工具调用后，重置重试预算和退避延迟，并将会话状态恢复为运行中。
- 默认 5 次上限改为按连续未恢复输出的重试计算；仅建立连接、收到开始事件或空内容不会重置计数，`maxAttempts: 0` 仍禁用该层自动重试。

## 测试

- 增加 Codex OAuth 对 GPT-6 模型版本识别和上下文限额保留的自动化测试。
- 增加思考和正文恢复后再次断线的回归测试，验证重试预算、运行状态和退避延迟重置，以及连续失败上限和禁用重试行为；重试与会话处理相关 48 项测试全部通过，后端类型检查通过。
